# Native files for AI Lesson Design Lab

The first guide already works online as an HTML guide, browser-based presentation walkthrough and A4 printable handout.

To make the **original file formats** downloadable from the guide, upload two public-safe files to this folder:

- `AI_Lesson_Design_Lab_Public.pptx` (sanitised presentation, guest sign-in slide removed)
- `Design_Lab_Cheat_Sheet.pdf` (original printable handout)

The guide automatically checks whether these exact paths exist, and shows native download buttons once both or either are present. It does not show broken links when they are absent.

**Important:** Never upload the original unsanitised deck to a public repository because it contains a guest password. Review all attachments, hidden notes and metadata before posting. Change the password if it is still valid.

The editable / downloadable public files have been prepared in the ChatGPT conversation which created this hub.
